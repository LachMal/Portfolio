SlimMom | Team Manual QA Project

Project Overview

SlimMom is a web application designed to support users in managing their diet, daily calorie intake, and food consumption.

This project was completed as part of the GoIT QA Engineer training programme by the TestVengers testing team.

The team was responsible for evaluating the application's functionality and visual consistency within a one-week testing period.

Project type: Team-based manual QA project

Testing period: One week

Testing focus: Functional testing, requirements analysis, UI testing, static testing, and defect reporting.

Testing Objectives

The main objectives were to:

- Verify that the application meets its functional requirements.
- Compare implemented features with the available specification.
- Identify functional and visual inconsistencies.
- Test workflows for authenticated and unauthenticated users.
- Check application behaviour across different device categories.
- Document defects and communicate test results.
- Prepare a final summary of the testing process.

Testing Process

1. Requirements Analysis

The team reviewed the technical specification, available application functionality, Swagger documentation, and supplied visual references.

This analysis helped identify the expected features, potential requirement gaps, and areas requiring further investigation.

2. Test Planning

Testing activities were organised using Trello.

A shared checklist was prepared and divided into two main user categories:

- Authenticated users
- Unauthenticated users

Testing was also organised across desktop, tablet, and mobile device categories.

3. Test Case Design and Execution

Team members were assigned specific testing responsibilities.

Jira was used to document test cases and defects. Failed test cases were linked to corresponding defect reports where applicable.

4. Defect Reporting

Identified issues were documented for further analysis and communication.

The testing process covered both functional failures and visual inconsistencies.

5. Test Summary

The team prepared a final testing report and project presentation documenting the testing activities and findings.
